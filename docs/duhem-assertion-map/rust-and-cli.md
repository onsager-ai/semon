- **Interactive stdio (MCP): kept native for now.** MCP integration speaks a long-lived bidirectional process and correlates ordered JSON-RPC lines; `cli/invoke` is one command with stdin and captured stdout/stderr. Disposition native until a structured reusable contract exists (about 2 rows).

Recovery measurements in Rust tests are diagnostic, not acceptance thresholds.
- **Concurrent resource isolation (#410 leases) — low priority, 0 rows need it.** No per-run lease contract for isolated files/ports/databases/credentials/cleanup. Keep current Rust CI shards until a mapped parallel claim requires a lease.
- **Coverage/report gates: satisfied by M1 and v0.7.0.** `duhem coverage` and `claim_scope` ship in v0.7.0; #531, #546, #544, #535, #567 and #574 are closed and shipped, so they are not blockers.
