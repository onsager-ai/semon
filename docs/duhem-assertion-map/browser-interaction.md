## Uncertain classifications and baseline limits

- `embed` is classified **internal** because it asserts `mountViewerApplication`/`mountNativeShell` ownership and old-handle destruction on an injected synthetic host. It remains an active CI assertion; classification describes its owner layer, not whether it is run.
- Browser version is pinned through Playwright `1.63.0`; `ubuntu-latest` and the Playwright-installed Chromium build are not pinned to an immutable OS/browser revision in this workflow. No pixel verdict is made for screenshots in these functional checks.
