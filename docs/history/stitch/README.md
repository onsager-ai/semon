# Retired design-generation evidence

Stitch is retired from the active UI workflow. This directory preserves the
former `.stitch/` files byte-for-byte, including their original relative paths,
source revisions, prompts, HTML and screenshots. Its DESIGN.md and tool output
are historical records, not instructions to use the retired integration or
current capability requirements. Some original relative links describe the old
location and remain provenance rather than live navigation.

Current applicable guidance lives in [the UI design brief](../../design/ui-design-brief.md)
and [the design workflow](../../design/ai-design-workflow.md). No UI baselines or
approval registries are replaced by this archive move.
